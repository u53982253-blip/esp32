# ESP32 Smart Home Automation System

## About the Project
This project is designed to help people with leg disabilities control household appliances conveniently using a smartphone.

## Features
- Control four appliances using an ESP32 and a four-channel relay module.
- Operate lights, fans, and other appliances using a phone webpage.
